# План упрощения src/

## Цель

Сделать код проще читать и менять, сохранив текущее поведение. Начать с
`src/auto_publish.clj`: 354 строки объединяют чтение источника, AI, журнал
попыток и отправку публикаций. Остальные файлы `src/` занимают 14–53 строки.

Это общий план для обсуждения, а не разрешение на реализацию. Основание —
разбор текущего кода и обсуждение в чате; отдельная спецификация не создана.

## Предлагаемая структура

| Файл | Ответственность |
| --- | --- |
| `src/sava_centar.clj` | URL источника, чтение списка и страницы события, HTML и разбор дат |
| `src/event_time.clj` | Текущее время Белграда и проверка актуальности события |
| `src/event_analysis.clj` | AI-промпт, подготовка анализа, проверка ответа |
| `src/ai_process.clj` | Запуск AI-процесса, лимиты вывода и завершение группы процессов |
| `src/auto_publish.clj` | Последовательность обработки, журнал попыток, очередь и отправка |
| `src/publish.clj` | Точка запуска и подключение зависимостей |

С учётом нового правила `AGENTS.md` (предпочтительно до 100 строк в `.clj`)
`local-now` и `future?` выделены в `event_time.clj`. Сценарий публикации и AI
используют его напрямую; разбор дат источника остаётся в `sava_centar.clj`.

## Что обязательно сохранить

- Существующий файл попытки запрещает повторную обработку ID.
- Запись попытки синхронизируется до обработки; итог заменяется атомарно.
- Потерянный ответ Telegram даёт `unknown`, без автоматического повтора.
- Некорректные данные источника и AI не допускают публикацию.
- Таймаут, лимиты вывода, завершение группы процессов и удаление временной
  папки AI продолжают работать.
- Публикации идут по датам, с прежней паузой и повторной проверкой актуальности.
- Новые исходники остаются на ly2k; существующая сборка подхватывает их.

## Критерий готовности

Чтение источника, время и анализ вынесены из `auto_publish.clj`, существующие
проверки проходят, поведение сохранено. Уменьшение общего числа строк не
обязательно: цель — понятные места изменений без новой архитектурной прослойки.
