## Question

После [выбора параметров AI-процесса](06-process-options.md) выполнить минимальную пробу на синтетическом событии без отправки в Telegram. Установить реальную схему NDJSON, извлечение финального ответа, нормальное завершение, обработку ошибки и отмены по таймауту. Эта работа нужна для решения о контракте интеграции, а не для реализации импортера. Записать версию, команду без секретов, результаты и ограничения; не утверждать надёжность непроверенных путей.

## Answer

Выполнен ровно один разрешённый пользователем вызов на синтетическом инструментальном концерте: OpenCode v2.0.27, `openai/gpt-6.1-sol`, standalone, агент с запретом всех инструментов. Код завершения 0, 4,37 секунды, stderr пуст. NDJSON содержит `step_start` и один завершённый `text`; `part.text` успешно разобран как JSON с решением `publish`, причиной и корректным русским текстом. Telegram не использовался.

Активная проверка ограничена согласованной одиночной успешной пробой. Ошибки и принудительный таймаут не проверены; гарантии завершения удалённого вычисления не установлены. Их безопасный контракт и критерии приёмки передаются в [решение о надёжности ежедневного запуска](04-publication-reliability.md), а не считаются подтверждёнными этой пробой.

Артефакт: [Проба процесса OpenCode: GPT-6.1 Sol](../assets/opencode-probe.md), включая stdout, условия и повторяемую проверку сохранённого ответа. Достаточно для обсуждения минимального контракта интеграции; не свидетельство готовности автоматической публикации.
